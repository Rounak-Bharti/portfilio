# Rounak Bharti - Personal Portfolio

## About the Project

This project is a personal portfolio website created to showcase my
skills, education, projects and contact information as a Web Designer
and Front-End Developer.

The website is designed with a clean and responsive interface that
works across desktop, tablet and mobile devices.
